# NBA Jam - Guess That Baller!

A retro arcade-style NBA player guessing game. Identify players from their portraits
before the shot clock expires and see how high you can score.

**Play the game:** https://alexpepperl.github.io/nba-jam-guess-who/

## How to play

1. Choose one of four difficulty levels, from Rookie to Diehard.
2. Pick an NBA era: the 1980s, 1990s, 2000s, 2010s or current players.
3. Name the player shown in each round.
4. Complete 10 rounds before the 60-second shot clock runs out.

## Features

- More than 3,600 unique NBA players across five eras
- Four difficulty levels for casual fans through basketball experts
- No-repeat rotation that cycles through each mode's roster before reshuffling
- Automatic photo verification that skips players without a usable headshot
- Arcade-inspired presentation and responsive layout
- No account, installation or build step required
